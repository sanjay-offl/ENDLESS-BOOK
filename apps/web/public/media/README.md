# Media Assets Directory

Drop your high-resolution media files into this directory:

- `hero.jpg`: Still, painterly, oil-painting feeling artwork of the wheel cart of bangles at golden hour under a soft cerulean and amber sky.
- `hero-loop.mp4`: Atmospheric, muted, looping film for the hero background (pauses automatically when off-screen).
- `footer-loop.mp4`: Atmospheric, muted, looping film for the footer backdrop (pauses automatically when off-screen).

Until video files are provided, the site gracefully falls back to the painterly artwork and soft ambient gradient transitions.
